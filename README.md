# الغمري للمواد الغذائية — نسخة Front-end فقط

واجهة React + TypeScript + Vite تعمل محليًا بدون Backend أو قاعدة بيانات خارجية. تستخدم هذه النسخة `localStorage` داخل المتصفح لحفظ المنتجات والطلبات للتجربة فقط.

## التشغيل على Windows
1. ثبّت Node.js إصدار LTS.
2. افتح هذا المجلد في VS Code.
3. افتح Terminal ونفّذ:

```bash
npm install
npm run dev
```

4. افتح الرابط الذي يعرضه Vite، غالبًا `http://localhost:5173`.

## مهم جدًا
هذه نسخة عرض محلية وليست نظامًا آمنًا للإنتاج. كلمة مرور لوحة الإدارة موجودة داخل JavaScript ويمكن استخراجها، والبيانات محفوظة على جهاز/متصفح المستخدم فقط ويمكن تعديلها أو مسحها. لا تستخدمها لاستقبال طلبات حقيقية أو ترفعها للعامة. لحماية حقيقية يجب إضافة Backend ومصادقة وصلاحيات وقاعدة بيانات. المنتجات الأربعة الموجودة أمثلة تجريبية وليست أسعارًا حقيقية.
